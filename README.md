### ⚡ 核心定位与原则 (Philosophy & Focus)

> 追求极简、高信息密度与无运行时代价的原生交互；恪守契约驱动与模块解耦的工程规范。

* **系统增强与交互基建**：深耕 Windows 全局热键流重构（AutoHotkey v2）、无依赖原生交互层优化与轻量化工作流。
* **开发者工具与上下文工程**：研发浏览器内代码库上下文提取扩展（MV3）、Godot 开发套件与跨端效率工具。
* **工程纪律与标准约束**：坚持显式优于隐式（Explicit over Implicit）、强类型安全保障与零框架依赖的原生轻量化原则。
