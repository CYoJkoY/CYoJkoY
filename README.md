### ⚡ Philosophy & Core Focus

> Pursuing minimal cognitive overhead, high information density, and zero-runtime-cost native interactions; enforcing contract-driven architecture and decoupled modular design.

* **Systems & Desktop Workflows**: Refactoring Windows input pipelines (AutoHotkey v2), low-level desktop interactions, and lightweight portable environments.
* **Developer Toolchains & Context Engineering**: Building client-side codebase ingestion extensions (MV3), Godot ecosystem tooling, and cross-platform developer utilities.
* **Engineering Discipline & Standards**: Prioritizing explicit over implicit interfaces, strict compile-time typing, and surgical, regression-free refactoring.
